# موقع نادي الفحيحيل — فريق تحت 15

موقع ثابت (HTML + CSS + JavaScript) بدون خطوة بناء، وقاعدة بياناته مشروع Supabase مستقل باسم **Fahaheel U15**.
لا يشارك سترايك أي كود أو بيانات أو دومين.

## الملفات
- `index.html` — الصفحة الوحيدة.
- `css/app.css` — ثيم الموقع. `css/sheet.css` — تصميم ورقة التمرين (كما هو في الصفحة الأصلية).
- `js/config.js` — عنوان قاعدة البيانات والمفتاح العام. `demo: true` يشغّل الوضع التجريبي ببيانات وهمية.
- `js/store.js` — حفظ البيانات (مع طابور للتغييرات عند انقطاع النت).
- `js/app.js`, `js/app2.js` — الأقسام. `js/sheet.js` — محرر ورقة التمرين.
- `supabase/schema.sql` — جداول قاعدة البيانات وصلاحياتها (مطبّقة على المشروع).

## النشر على دومين مجاني
ارفع المجلد كما هو على Vercel أو Netlify أو GitHub Pages (بدون أي إعدادات بناء).
بعد النشر:
1. في Supabase ← Authentication ← URL Configuration: حط رابط الموقع في Site URL.
2. أضف إيميلات الطاقم في جدول `staff` (عمود `email`) — الدخول مسموح فقط للإيميلات المسجلة فيه.
3. كل واحد من الطاقم يفتح الموقع ← «أول مرة؟ فعّل حسابك» ويختار كلمة مروره.

للتجربة بدون قاعدة بيانات: افتح الرابط مع `?demo` في آخره.
